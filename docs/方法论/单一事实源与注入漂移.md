# 单一事实源与注入漂移

## 来源事故

M4 排雷：gatekeeper.html 内联引擎副本与 gates.mjs 两套并存，规则改 A 漏 B（雷区 R-01）。

## 规则

1. 每类事实只有一个可改处：门禁规则=`gates.mjs`、渲染纯函数=`render-core.mjs`、配置=`configs/*.json`、版本=CHANGELOG 顶部。
2. HTML 侧三处标记区（GATES-SRC/CONFIGS-SRC/RENDER-SRC）是生成物，勿手改；改源后 `node sync-*.mjs` 重注入。
3. 改核心规则走全链回归：重注入 → `--check` → 负样本单测 → 样例五裁决逐字基线 → bench（AGENTS SOP-1）。

## 验证方法

`node sync-gates.mjs --check && node sync-configs.mjs --check && node sync-render.mjs --check` 三绿；已并入一键门禁。

## 出处

雷区 R-01；ROADMAP M4；AGENTS.md SOP-1。
