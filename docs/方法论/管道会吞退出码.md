# 管道会吞退出码

## 来源事故

v0.15.6 补丁提交时门禁经管道调用，非零退出码被吞、漂移漏放行，后被 gate.mjs 一键门卫拦截（commit d540b1c，雷区 R-08）。M15 落地当天又连续两次现行犯：取证命令 `cmd | tail` 后取 `$?` 拿到的是 tail 的退出码（首跑留证文件在案）。

## 规则

1. 门禁一律经 `tools/gate.mjs` 串行执行（逐门 spawn、逐门断 exit code），禁止管道包裹。
2. 手工取证需要看输出又要拿退出码：`out=$(cmd); s=$?; echo "$out" | grep xxx; echo "exit=$s"`——先存变量再过滤。
3. 提交命令绝不与门禁命令串链连跑（`gate | tail && git commit` 是反模式：tail 恒绿会放行红灯提交）。

## 验证方法

`node tools/gate.mjs` 任一门注入失败 → 整体 exit 1（雷区表 R-08 验证列）。

## 出处

commit d540b1c；雷区 R-08；output/doc-sync-first-run.md「R-08 现行犯记录」。
