# 诚实口径与假设区间标注

## 来源事故

早期提效叙事曾用"纯计算耗时 vs 人脑阅读时间"算出 44 万倍，被判夸大（交接文档「三」在案）。

## 规则

1. 提效/对比数字只用可复算口径："分钟级→秒级端到端 + 零漏检 + 可审计"；禁比值式夸大。
2. 人工基线必须标为"假设区间"而非秒表实测；未实测的说法不得写成已实测。
3. 同源限定语分档：证据只支撑"实现正确"就不得说"经官方验证"（源仓竞赛项目对官方计算器取证的纪律）。
4. 合成数据/未复核内容保留标注，不得为好听改写成真实口径。

## 验证方法

对外材料中的每个数字回答三问：口径是什么？谁能复算？有没有超出证据的限定词被删？

## 出处

交接文档「三」；README 核心指标引用式表述约定。
