# 可选配置形参保零回归

## 来源事故

M10 project-config 引入换配置能力时的设计约束：给引擎加能力不能改变旧调用点的行为（样例五裁决曾因一次放宽念头差点漂移）。

## 规则

1. 引擎新能力一律走可选参数：`analyze(doc, cfg = DEFAULT_CONFIG)`——DEFAULT_CONFIG 逐字复刻旧行为，旧调用点不带 cfg 即行为不变。
2. 回归红线 = 样例五裁决逐字基线：A 阻断/0 分/4×P0、B 49、C 17、D 84、E 100（verify.mjs 12 项断言 + VERIFY_TOTAL 自洽锁）。
3. 断言总数变更必须同步 `VERIFY_TOTAL` 常量（实跑≠声明即红）。

## 验证方法

`node verify.mjs` 全绿（12 项 + 自洽行）；任何引擎改动前后输出逐字比对。

## 出处

CHANGELOG v0.11.0（M10）/ v0.18.0（M15-T2 自洽锁）；交接文档「三」。
