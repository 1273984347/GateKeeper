# 正则锚定语境：度量值/编号必须防误判

## 来源事故

M8.5 Self-DRL：G2 版本检测把 `0.07ms / 16.2ms` 等测量值、`M8.5` 里程碑号误判为版本号（假阳性，7/7 阻断的成因之一）——CHANGELOG v0.10.0。

## 规则

1. 匹配"版本号"类结构必须强制语境前缀：`\bv\d+(?:\.\d+)+`（`v` 前缀 + 词边界）。
2. 配套书写规范：版本号一律 `vX.Y.Z` 三段式；度量值带单位；里程碑用 `M#`。
3. 新正则上线先跑负样本：把已知"长得像但不该命中"的串列为固定反例（gates.test.mjs）。

## 验证方法

`node --test gates.test.mjs`（含版本正则反例）；雷区表 R-09。

## 出处

CHANGELOG v0.10.0；交接文档「三」「六」R-09。
