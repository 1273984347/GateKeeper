# 视觉验收闭环 · UI/截图变更的逐页判定流程（M14-T1）

> 来源：M14 内部协作仓经验移植（内部协作仓 AGENTS.md「验收 Prompt 模板」+ SOP-3 闭环，本地化）。
> 读者：执行 UI 变更的 Agent。本文件自包含，按此走完五步才算视觉交付完成。

## 一、适用范围与三道关分工

凡改动 `gatekeeper.html` 渲染效果、更换 README 配图、新增 `screenshots/` 截图，必须走本闭环。三道关互不替代：

| 关 | 工具 | 管什么 |
|---|---|---|
| 1 | `node tools/smoke.mjs` | 运行时行为：0 error / 暗色 / 640 / ④ 阻断态按钮禁用 / ④b 放行态 toast / 快捷键 / 粘贴全链路（**七项**） |
| 2 | [UI升级方案.md](../../UI升级方案.md) §7 | 设计规格量化：令牌值 / 间距 / 响应式断点 |
| 3 | **本闭环** | 视觉判定：溢出/裁剪/重叠/失衡/图表渲染/对比度/乱码——程序化检查抓不住的"人眼可见缺陷" |

## 二、五步闭环

```
① 渲染   → Playwright 截图（正式成品落 screenshots/，过程临时件落 output/，命名 visual-tmp-*）
② 逐页判定 → 验收 agent 按 §三 模板逐张 Read，每页输出一行 JSON
③ 修复   → must_fix 逐条修复，禁止只修截图能过的表面项
④ 复检   → 重新渲染 → 重新逐页判定，overall=pass 才算过
⑤ 留证   → 判定 JSON 原文落 output/visual-accept-<主题>.md（日期+对象+判定人+逐页 JSON+overall），清理 visual-tmp-*
```

## 三、验收 Prompt 模板（逐字使用，替换【】部分）

```
你是视觉验收员。请 Read 以下【N】张渲染页 PNG：
【逐行列出绝对路径】
本轮修复点：【上轮问题与修复方式；首轮写"首轮基线验收，无上轮修复"】
重点核对：【本轮变化点】
通用检查：溢出/裁剪/重叠/失衡/图表渲染/对比度/乱码。
工具豁免声明：【如"Playwright 中文字形渲染微差不报；?demo=1 演示占位数据不报"】。
输出每页一行 {"page":N,"verdict":"pass|fail","issues":[...]}，
最后 {"overall":"pass|fail","must_fix":[...]}。只报真实可见问题。
```

## 四、像素采样法（第四步复检的定量补充）

目检有争议时用像素采样裁决，规则：

1. **可见性**：目标元素区域内非背景色像素占比 >90% 判可见（防白底白图形、深底板盖浅图形）；
2. **动效静态回退**：Playwright `new_context(reduced_motion="reduce")` 仿真 + `getAnimations().length==0`，确认关动画后元素回到**可见基样式**而非声明初值（防 r=0 消失、基线白格丢色类事故）；
3. **页脚/贴底元素**：采样其背景色与坐标，确认未被后续内容挤出安全区。

## 五、判定纪律

- 只报真实可见问题；不得为让 overall=pass 而放宽判词（与 verify 红线"绝不放水"同源）。
- overall=fail 连续两轮修不过：停止迭代，向用户报告缺陷本身（先修缺陷再谈交付，M14 方案 §四止损线）。

## 六、A / AL 系列判据检查点（与门序列对齐 · v0.21.3 补）

> 本闭环管「程序化抓不住的可见缺陷」；A / AL 系列由脚本机械判定。**本节不重复判定**，只列各判据的归属与「人工仍需额外确认的点」，避免同一判据两套口径。

| 判据 | 机械判定载体 | 门序列 | 人工在本闭环需额外确认的点 |
|---|---|---|---|
| A1 间距刻度 | lint-layout 的 AL7 | 第十三门 | 无（纯声明级） |
| A2 字号阶梯 | lint-ui | 第十二门 | 中文字号是否过密/过疏（脚本只管数值档位） |
| A3 圆角档位 | lint-ui | 第十二门 | 圆角与整体观感是否冲突（脚本只管越档） |
| A4 hover 位移 | lint-ui | 第十二门 | 位移是否造成相邻元素碰撞（脚本不判重叠） |
| A5 焦点态 | lint-ui | 第十二门 | 键盘实走一遍，焦点环是否被裁切/不可见 |
| A6 语义色可辨 | lint-ui | 第十二门 | P0–P3 四色在真实卡片上是否仍能区分（脚本只算亮度差） |
| A7 辅助文本对比度 | lint-ui + contrast-probe | 第十二门 / 独立 | 深色底上的次要文字是否偏暗 |
| A8 关键数字等宽 | lint-ui | 第十二门 | 数字纵向刻度是否对齐（脚本只判 font-family） |
| A9 功能零回归 | smoke + verify | 门序列 | 无 |
| A10 定位后可达 | lint-layout 的 AL10 | 第十三门 | 定位后目标是否真的在视口内可见 |
| A11 结构零回归 | class-audit | 第十一门 | 无 |
| A12 体积 | lint-ui | 第十二门 | 无 |
| A13 衬线残留 | lint-ui | 第十二门 | 字标是否仍需品牌衬线（脚本只判残留） |
| AL1–AL11 布局结果 | lint-layout | 第十三门 | 页面观感是否失衡（脚本管几何，不管观感） |

> **判据归属纪律**：同一判据只由一个门承担；本闭环**不重复判定** A / AL 系列，只在其通过后做「人眼可见缺陷」的补充判定。
